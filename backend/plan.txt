# Frontend (React)
#       │
#       │  POST /heal  { domain, incident_type, source_content, error_signature }
#       ▼
# Flask Backend
#       │
#       ├─ 1. HASHER — hashlib(error_signature + source_content) → unique ID
#       │
#       ├─ 2. CACHE CHECK — ID in cache.json?
#       │         YES → return cached fix instantly (log "Cache Hit")
#       │         NO  → continue
#       │
#       ├─ 3. PROMPT FACTORY — build domain-specific prompt → Gemini
#       │         returns: fixed_code + pytest_script
#       │
#       ├─ 4. DOCKER GUARDRAIL
#       │         write pytest to /sandbox/test_fix.py
#       │         docker run pytest → exit code?
#       │              0 → PASSED → save to cache → return result
#       │              1 → FAILED → feed error back to Gemini (self-correct)
#       │                    └─ retry once more → docker again
#       │                         0 → PASSED
#       │                         1 → BLOCKED (hallucination caught)
#       │
#       └─ 5. SSE STREAM → Frontend live console
      
# Frontend receives:
#   - diff (original vs fixed)
#   - docker logs (live)
#   - verdict (HEALED / SELF-CORRECTED / BLOCKED)
#   - ROI stats (cache hits, hallucinations blocked)
